# Chalkless

A cross-platform digital chalkboard application built with .NET and Avalonia.

Chalkless is intended for solving math problems in an intuitive and fun way by using a graphics tablet.
Currently, this app is in early development and more features will be added gradually.
Feel free to open an issue if you find any bugs or have suggestions for new features.

## Gettting started
### Prequisites
- .NET 10.0 SDK
- Git
### Clone repository
```
git clone https://github.com/jurgis-jezupovs/chalkless.git
cd chalkless
```
### Run the project
```
dotnet run
```
